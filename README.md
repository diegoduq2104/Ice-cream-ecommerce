🍦 Scoopl - E-commerce de Helados
Proyecto de comercio electrónico desarrollado con WordPress para la heladería Scoopl.

🛠️ Tecnologías utilizadas
WordPress: Sistema de gestión de contenidos.
PHP: Funciona para administrar, guardar y verificar el pedido de una compra. 
JS: Se utiliza mayormente, para inyectar dinamicamente los formularios ocultos de Woocommerce.
Git/GitHub: Control de versiones, para el seguimiento de cambios y colaboración.
